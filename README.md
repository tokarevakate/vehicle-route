# Выбор экономичной скорости автомобиля по маршруту

Веб-приложение строит по GPS-точкам профиль маршрута (высота, уклон, радиус поворота) и рассчитывает профиль скорости с минимальным модельным расходом топлива. Результат показывается на карте.

Ветка `feat/model-maturity-dp-mpc` содержит физическую модель автомобиля и два алгоритма: pointwise baseline и глобальное динамическое программирование (DP). Метод MPC в этой ветке пока не реализован.

## Структура

```
vehicle-route/
├── configs/default.yaml     # маршрут, автомобиль, параметры оптимизации
├── docs/model-maturity.md   # описание модели версии 2
├── route_*.csv              # данные маршрутов
├── tests/                   # pytest
└── webapp/
    ├── app.py               # FastAPI: /api/route, /api/metrics
    ├── config.py            # загрузка и проверка конфигурации
    ├── profile_model.py     # профиль маршрута: сплайн высоты, уклон, кривизна
    ├── vehicle_model.py     # силы сопротивления, тяга, КПД, переход между скоростями
    ├── optimization.py      # pointwise baseline и DP
    └── static/              # интерфейс (Leaflet, Chart.js)
```

Подробности модели: [docs/model-maturity.md](docs/model-maturity.md).

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r webapp/requirements.txt -r requirements-dev.txt
pytest
uvicorn webapp.app:app --reload
```

Приложение открывается по адресу `http://127.0.0.1:8000`. Leaflet и Chart.js загружаются из интернета.

## Конфигурация

Параметры хранятся в `configs/default.yaml`. Другой файл можно указать переменной окружения `VEHICLE_ROUTE_CONFIG`. Правила загрузки:

- если файл указан явно (через переменную) и не найден, запуск завершается ошибкой;
- если не найден файл по умолчанию, используются встроенные значения и пишется предупреждение;
- неизвестные ключи игнорируются с предупреждением в логе;
- значения проверяются: шаг скорости больше нуля, `v_min <= v_max`, `accel_min < 0 < accel_max`, `default_algorithm` из списка `pointwise`, `dp`.

## API

| Метод | Адрес | Описание |
|-------|-------|----------|
| GET | `/` | интерфейс |
| GET | `/api/route?algorithm=pointwise\|dp` | профиль скорости и показатели; без параметра берётся `default_algorithm` |
| GET | `/api/metrics` | показатели уже посчитанных алгоритмов; `?compute=true` считает все |

Если расчёт недопустим, `/api/route` отвечает кодом 422 с полем `status`. Нефинитные значения в `/api/metrics` возвращаются как `null`.

## Алгоритмы

- **pointwise** — в каждой точке подбирается скорость с наименьшим установившимся расходом, затем профиль ограничивается по ускорению вперёд и назад.
- **dp** — состояние: скорость на сетке вдоль маршрута. Минимизируется сумма расхода топлива, штрафа за время, тормозной энергии и ускорения при ограничениях на боковое и продольное ускорение, силу и мощность. Если ограничение по кривизне ниже `v_min_kmh`, сетка скоростей расширяется вниз, и в таких точках выбирается наибольшая допустимая скорость.

## Ограничения

- Карта двигателя не используется, КПД задан аналитической аппроксимацией. Результаты подходят для сравнения алгоритмов, но не для точного прогноза расхода конкретного автомобиля.
- Коэффициенты не проверялись на измерениях.
- Веса штрафов (`time_weight_l_per_s`, `accel_weight`) заданы эвристически. Их влияние на результат не исследовано.
- Время в панели интерфейса показывает длительность анимации, а не расчётное время поездки.
- Интерфейс пока не выбирает алгоритм и не показывает `/api/metrics`.
