# Глава 1. Постановка задачи

## 1.1. Цель лабораторной работы

Целью работы является разработка и исследование веб-приложения для оптимизации расхода топлива автомобиля на заданном маршруте с учётом геометрии местности (профиль высот, уклоны, кривизна) и применения искусственного интеллекта для восстановления недостающих данных и аппроксимации зависимости расхода топлива от скорости и параметров дороги.

## 1.2. Исходные данные и параметры

Исходными данными являются:

- CSV-файл маршрута с ~8000 точками, содержащий:
  - координаты точек маршрута (широта/долгота либо проекция на ось дороги);
  - высоту над уровнем моря для каждой точки (при наличии);
  - при наличии — фактическую скорость и/или измеренный расход топлива;
- параметры автомобиля (масса, аэродинамические характеристики, коэффициент сопротивления качению и др.);
- ограничения по скорости и динамике (ограничения ПДД, максимальное допустимое поперечное ускорение и др.).

Для одной конфигурации транспортного средства используются постоянные параметры:

- масса автомобиля m;
- коэффициент аэродинамического сопротивления Cd и фронтальная площадь Af;
- коэффициент сопротивления качению f_roll(v) — квадратичная зависимость от скорости по ISO 28580;
- плотность воздуха ρ и ускорение свободного падения g.

Эти параметры применяются для расчёта сил сопротивления движению и требуемой тяговой мощности.

## 1.3. Задача реконструкции маршрута и уклонов (ИИ-модель №1)

Первая подзадача заключается в восстановлении детализированного профиля маршрута по неполному CSV-файлу. Исходный файл содержит около 8000 точек, в то время как для целей моделирования требуется более плотная дискретизация (например, 10000 точек).

Необходимо:

1. Выполнить параметризацию маршрута по длине пути s, вычислив накопленную длину между последовательными точками (формула гаверсинуса).
2. Построить интерполяционную ИИ-модель зависимости высоты от пройденного расстояния h(s), обеспечивающую непрерывный и гладкий профиль рельефа без нефизичных осцилляций.
3. На основе модели h(s) выполнить пере-дискретизацию маршрута на равномерной сетке по расстоянию, получив 10000 точек sk и соответствующие значения высоты hk.
4. Рассчитать уклон Gk (градиент дороги) для каждой точки по первой производной h(s) по расстоянию.
5. По геометрии траектории (изменение курсового угла между соседними точками) оценить радиус кривизны Rk на каждом участке.

Искусственный интеллект на данном этапе реализован в виде **кубического сплайн-интерполятора** (`scipy.interpolate.CubicSpline`), который восстанавливает непрерывную функцию высоты h(s) по заданным дискретным точкам. В отличие от полиномиальной регрессии высокой степени, кубический сплайн не даёт эффекта Рунге на длинных маршрутах и обеспечивает устойчивое вычисление уклонов через аналитическую первую производную.

## 1.4. Модель расхода топлива (ИИ-модель №2)

Вторая подзадача заключается в построении модели расхода топлива как функции скорости, уклона, кривизны дороги и продольного ускорения.

### 1.4.1. Физическая основа

Для короткого сегмента маршрута длиной Δs_j с уклоном Gj и радиусом кривизны Rj суммарная тяговая сила определяется как:

F_drive(v, Gj, a) = F_aero(v) + F_roll(v) + F_grade(Gj) + m · a,

где:

- F_aero(v) = 1/2 · ρ · Cd · Af · v² — аэродинамическое сопротивление;
- F_roll(v) = m · g · f_roll(v) — сопротивление качению с квадратичной зависимостью от скорости:

  f_roll(v) = f0 · (1 + v/147 + 0,3 · (v/147)²),

  где скорость v задаётся в км/ч (ISO 28580);
- F_grade(Gj) = m · g · (Gj/100) — составляющая веса на уклоне;
- m · a — инерционный член при продольном ускорении a (м/с²).

При квазистационарном движении (a = 0) выражение сводится к классическому балансу сил сопротивления. Требуемая мощность:

P_drive(v, Gj, a) = F_drive · v.

### 1.4.2. Эмпирическая ИИ-модель расхода

Для практического использования вводится эмпирическая ИИ-модель удельного расхода топлива q:

q(v, Gj, Rj, a) = a0 + a1·v + a2·v² + b1_up·max(Gj, 0) + b1_down·min(Gj, 0) + c1·(v²/Rj) + d1·v·a,

где:

- q — удельный расход топлива [л/100 км];
- v — скорость [км/ч];
- Gj — уклон в процентах (может быть отрицательным на спусках);
- Rj — радиус кривизны [м];
- a — продольное ускорение [м/с²];
- b1_up > 0 — коэффициент увеличения расхода на подъёмах;
- b1_down ≈ 0 — коэффициент на спусках (режим overrun/fuel-cut — расход стремится к минимуму);
- d1 — VSP-коэффициент перекрёстного члена скорости и ускорения (Vehicle Specific Power);
- коэффициенты a0, a1, a2, b1_up, b1_down, c1, d1 калибруются автоматически из физической модели через МНК (`FuelCoeffs.from_vehicle`).

Модель отражает:

- наличие оптимальной скорости с минимальным расходом (квадратичная компонента по v);
- асимметрию уклона: подъём увеличивает расход, спуск переводит двигатель в режим overrun с близким к нулю расходом;
- дополнительные потери в поворотах (член c1·v²/R);
- штраф за ускорение/торможение согласно VSP-подходу EPA/MOVES (член d1·v·a).

## 1.5. Оптимизация скорости по маршруту

На основе восстановленного профиля маршрута и модели расхода топлива формулируется задача оптимизации скорости.

Для каждого сегмента j задаются ограничения по скорости:

- минимально допустимая скорость v_min;
- максимальная скорость по ПДД v_max^ПДД;
- динамическое ограничение по поперечному ускорению:

  v_max^дин(Rj) = sqrt(a_y,max · Rj),

  где a_y,max — максимально допустимое поперечное ускорение (по умолчанию 2,0 м/с²).

Итоговое ограничение:

v_max(Rj) = min(v_max^ПДД, v_max^дин(Rj)).

Задача поиска оптимальной скорости на сегменте:

v_j* = argmin_{v ∈ [v_min, v_max(Rj)]} q(v, Gj, Rj, a),

где q задаётся ИИ-моделью №2. Минимум находится численно методом `scipy.optimize.minimize_scalar` (bounded Brent), что корректно обрабатывает любые нелинейные члены модели.

Суммарный расход топлива по маршруту:

Q = Σ_j q(v_j*, Gj, Rj) · (Δs_j / 100),  [л]

где Δs_j — длина сегмента в километрах. Время в пути:

T = Σ_j (Δs_j / v_j*).

Основная цель — минимизировать суммарный расход топлива Q при соблюдении ограничений по скорости.

## 1.6. Роль веб-приложения и визуализация результатов

Разрабатываемое веб-приложение выполняет следующие функции:

1. Принимает на вход CSV-файл маршрута и параметры автомобиля.
2. Запускает ИИ-модель №1 (CubicSpline) для восстановления полного профиля высоты и уклонов на заданном количестве точек.
3. Для каждого сегмента маршрута калибрует ИИ-модель №2 из физической модели сил и вычисляет оптимальную скорость через `minimize_scalar`.
4. Рассчитывает накопленный расход топлива вдоль маршрута в литрах.
5. Визуализирует результаты:
   - отображает маршрут на карте с анимацией движения транспортного средства и выделением пройденного пути;
   - отображает текущую скорость, время в пути и расход топлива;
   - строит графики высоты и уклона вдоль маршрута;
   - выводит рассчитанную оптимальную скорость.

Таким образом, веб-приложение интегрирует физически обоснованные расчёты с ИИ-моделями реконструкции маршрута и оценки расхода топлива, предоставляя наглядный инструмент для анализа влияния профиля дороги и скорости на расход топлива.
