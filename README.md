# Определение расхода топлива и выбор экономичной скорости движения автомобиля по маршруту

Веб-приложение, которое по GPS-точкам маршрута строит его профиль (высота, наклон дороги, крутизна поворотов), рассчитывает для каждого участка скорость с наименьшим расходом топлива и показывает результат на карте.

## Аннотация

В работе решается задача выбора скорости автомобиля на каждом участке маршрута так, чтобы расход топлива был минимальным. Решение состоит из двух расчётных модулей и веб-интерфейса. Первый модуль по набору GPS-точек строит плавную кривую высоты маршрута (кубический сплайн, то есть кривая, составленная из гладко стыкующихся кусков многочленов третьей степени), а затем вычисляет наклон дороги и радиус поворота. Второй модуль содержит формулу расхода топлива. Её коэффициенты получены из расчёта сил, которые тормозят автомобиль (сопротивление воздуха, качения колёс и подъёма). Затем для каждой точки маршрута подбирается скорость, при которой расход по этой формуле наименьший. Результаты передаются в браузер через REST API (запрос к серверу по адресу `/api/route`) и отображаются на интерактивной карте.

## 1. Постановка задачи

Маршрут задан последовательностью точек $(\varphi_i, \lambda_i, h_i)$, где $\varphi_i$ — широта, $\lambda_i$ — долгота, $h_i$ — высота над уровнем моря. Для каждой точки нужно найти скорость $v^*$, при которой удельный расход топлива $q$ (л/100 км) наименьший, при заданных ограничениях на скорость:

$$
v^* = \arg\min_{v \in [v_{\min},\, v_{\max}(R)]} q(v, G, R, a),
$$

где $G$ — наклон дороги (%), $R$ — радиус поворота (м), $a$ — ускорение автомобиля вдоль движения (м/с²).

## 2. Структура проекта

Серверная часть написана на Python с использованием фреймворка FastAPI. Клиентская часть — статическая страница на JavaScript.

## 3. Модуль профиля маршрута

Реализован в файле `webapp/profile_model.py`.

### 3.1. Чтение данных

Столбцы широты, долготы и высоты определяются автоматически по их названиям (`lat`, `lon` или `lng`, `elevation` или `alt` и другие). Если столбца высоты нет, высота считается равной нулю. Пройденное расстояние $s_i$ получается сложением расстояний между соседними точками. Каждое расстояние считается по формуле гаверсинусов, то есть как кратчайший путь по поверхности шара радиусом $R_\oplus = 6\,371\,000$ м (приближённая форма Земли).

### 3.2. Высота и наклон дороги

Высота как функция расстояния $h(s)$ приближается кубическим сплайном (`scipy.interpolate.CubicSpline`), который проходит через все заданные точки $(s_i, h_i)$. Точки с одинаковым расстоянием перед этим удаляются. Наклон дороги равен скорости изменения высоты, то есть производной сплайна:

$$
G(s) = 100 \cdot \frac{dh}{ds}.
$$

Сплайн выбран вместо одного многочлена высокой степени, потому что на длинных маршрутах такой многочлен даёт ложные «волны» около концов участка (эффект Рунге), которых в реальной дороге нет.

### 3.3. Выравнивание шага точек и радиус поворота

Исходные точки расположены неравномерно, поэтому маршрут пересчитывается в заданное число точек (по умолчанию 10 000) с одинаковым шагом по расстоянию. Широта и долгота определяются линейной интерполяцией (по прямой между соседними точками), высота и наклон берутся из сплайна. Радиус поворота в точке $i$ оценивается по тому, насколько изменилось направление движения между двумя соседними отрезками:

$$
R_i = \left| \frac{\overline{ds}}{\Delta\theta_i} \right|, \qquad \overline{ds} = \frac{s_{i+1} - s_{i-1}}{2},
$$

где $\Delta\theta_i$ — изменение направления движения (угол в радианах, приведённый к интервалу от $-\pi$ до $\pi$). Если $|\Delta\theta_i| < 10^{-6}$, участок считается прямым, и радиус не определяется (значение `None`).

## 4. Модуль расхода топлива

Реализован в файле `webapp/consumption_model.py`.

### 4.1. Формула расхода

Удельный расход топлива считается по эмпирической формуле, то есть по зависимости, которая описывает результат, но не выводится из устройства двигателя:

$$
q = a_0 + a_1 v + a_2 v^2 + b_{\uparrow}\max(G, 0) + b_{\downarrow}\min(G, 0) + c_1 \frac{v^2}{R} + d_1 v a,
$$

где $v$ — скорость (км/ч). Слагаемые описывают:

- $a_0 + a_1 v + a_2 v^2$ — расход на ровной дороге в зависимости от скорости;
- $b_{\uparrow}\max(G, 0)$ — дополнительный расход на подъёме;
- $b_{\downarrow}\min(G, 0)$ — изменение расхода на спуске;
- $c_1 v^2 / R$ — дополнительные потери в повороте;
- $d_1 v a$ — дополнительный расход при разгоне.

Значение $q$ не может быть меньше 0,5 л/100 км.

### 4.2. Подбор коэффициентов

Коэффициенты не подбираются по измерениям на реальном автомобиле. Они вычисляются из расчёта сил, действующих на автомобиль (`FuelCoeffs.from_vehicle`). Параметры автомобиля по умолчанию:

- масса 1500 кг;
- коэффициент аэродинамического сопротивления $c_d = 0{,}29$;
- лобовая площадь 2,2 м²;
- плотность воздуха 1,2 кг/м³;
- базовый коэффициент сопротивления качению колёс 0,01.

Мощность, которую двигатель должен передать на колёса, равна сумме четырёх сил: сопротивления воздуха, сопротивления качения (растёт с ростом скорости), силы тяжести на уклоне и силы инерции при разгоне. Расход топлива получается из этой мощности с учётом энергии, заложенной в топливе (43,4 МДж/кг), плотности топлива (0,74 кг/л), КПД двигателя (0,25) и расхода на холостом ходу (0,6 л/ч).

Коэффициенты находятся в три этапа:

1. Коэффициенты $a_0, a_1, a_2$ подбираются методом наименьших квадратов, то есть так, чтобы кривая как можно ближе проходила к расчётным значениям на ровной дороге при скоростях от 10 до 130 км/ч.
2. Коэффициент $b_{\uparrow}$ определяется как наклон прямой, подогнанной к приросту расхода при скорости 80 км/ч и наклонах дороги 0, 3, 5 и 8 %. Для спусков (−8, −5, −3 и 0 %) выполняется такая же подгонка. При этом расход не может опуститься ниже 15 % от расхода на ровной дороге, потому что при торможении двигателем подача топлива почти прекращается.
3. Коэффициент $d_1$ определяется по приросту расхода при разгоне с ускорением 1 м/с² на скорости 80 км/ч.

Коэффициент $c_1 = 0{,}002$ задан как постоянное число и не подбирается. Для параметров автомобиля по умолчанию получены значения $a_0 \approx 6{,}70$, $a_1 \approx -0{,}0811$, $a_2 \approx 0{,}000881$, $b_{\uparrow} \approx 1{,}83$, $d_1 \approx 0{,}234$.

### 4.3. Выбор скорости

Для каждой точки профиля ищется скорость с наименьшим значением $q$ на отрезке от $v_{\min}$ до $v_{\max}$ (`scipy.optimize.minimize_scalar`, метод `bounded`). В поворотах верхняя граница снижается так, чтобы боковое ускорение не превышало $a_{y,\max} = 2{,}0$ м/с²:

$$
v_{\max}(R) = \min\left(90,\; 3{,}6\sqrt{a_{y,\max} R}\right).
$$

Нижняя граница $v_{\min} = 30$ км/ч важнее верхней: если допустимая в повороте скорость оказывается ниже 30 км/ч, всё равно принимается 30 км/ч. Ускорение при выборе скорости принимается равным нулю, то есть разгон и торможение между точками не рассматриваются.

### 4.4. Суммарный расход

Расход на участке между соседними точками равен $q \cdot \Delta s / 100$ (в литрах, если $\Delta s$ выражено в километрах). Эти значения складываются вдоль маршрута (поле `fuel_cumulative`). Для маршрута из `route_sochi.csv` длиной около 8,47 км найденные скорости лежат в диапазоне 30–46 км/ч, суммарный расход составляет около 4,68 л.

## 5. Программный интерфейс

| Метод | Адрес | Описание |
|-------|-------|----------|
| GET | `/` | главная страница приложения |
| GET | `/api/route` | профиль маршрута с экономичной скоростью |
| GET | `/static/*` | файлы интерфейса |

Ответ на запрос `/api/route` имеет вид `{"points": [...]}`. Каждая точка содержит поля:

- `index` — номер точки;
- `lat`, `lon` — широта и долгота;
- `elevation` — высота (м);
- `distance` — пройденное расстояние (м);
- `grade` — наклон дороги (%);
- `radius` — радиус поворота (м) или `null` на прямом участке;
- `speed_optimal` — экономичная скорость (км/ч);
- `fuel_proxy` — удельный расход (л/100 км);
- `fuel_cumulative` — суммарный расход с начала маршрута (л).

## 6. Пользовательский интерфейс

Интерфейс включает:

- карту (Leaflet) с маршрутом, маркером текущего положения и уже пройденным участком;
- спидометр, который показывает экономичную скорость в текущей точке (шкала 0–90 км/ч);
- панель показателей: время воспроизведения, пройденное расстояние, текущий наклон дороги;
- график высоты и наклона дороги (Chart.js) с отметкой текущей позиции;
- кнопки управления воспроизведением: пауза, переход в начало, шаг на 10 точек назад и вперёд, ползунок положения, скорость воспроизведения 0,5×, 1×, 2×, 4×.

Время в панели показателей — это время работы анимации, а не расчётное время поездки по маршруту.

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r webapp/requirements.txt
```

## 8. Ограничения

- Скорость выбирается для каждой точки отдельно. Плавность перехода между соседними точками и предельное ускорение автомобиля не учитываются, поэтому такой профиль скорости можно проехать на практике лишь приближённо.
- Ограничение скорости по правилам дорожного движения задано одним значением, 90 км/ч, на весь маршрут.
- Формула расхода не проверялась на реальных измерениях. Её коэффициенты следуют из принятых допущений о физике автомобиля.
- В текущей версии кода коэффициент $b_{\downarrow}$ равен 0. Результат подгонки для спусков ограничивается сверху нулём (`min(b1_down, 0.0)`), хотя сама подгонка даёт положительное число. Поэтому экономия топлива на спусках в расчёте не учитывается.
- Слагаемое $d_1 v a$ на результат не влияет, потому что скорость выбирается при $a = 0$.
- Параметры автомобиля и маршрут задаются в коде и не меняются через интерфейс.

## 9. Возможные направления развития

- Исправление ограничения для $b_{\downarrow}$ и учёт торможения двигателем на спусках.
- Построение профиля скорости, который можно реально проехать, с ограничением на ускорение (метод динамического программирования по расстоянию).
- Подбор и проверка коэффициентов расхода по измерениям на реальном автомобиле.
- Расчёт времени в пути и поиск компромисса между временем и расходом топлива.
- Загрузка маршрута и ввод параметров автомобиля через интерфейс.
