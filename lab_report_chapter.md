# Глава 1. Постановка задачи

## 1.1. Цель лабораторной работы

Целью работы является разработка и исследование веб-приложения для оптимизации расхода топлива автомобиля на заданном маршруте с учётом геометрии местности (профиль высот, уклоны, кривизна) и применения искусственного интеллекта для восстановления недостающих данных и аппроксимации зависимости расхода топлива от скорости и параметров дороги.

## 1.2. Исходные данные и параметры

Исходными данными являются:

- CSV-файл маршрута с ~8000 точками, содержащий:
  - координаты точек маршрута (широта/долгота либо проекция на ось дороги);
  - высоту над уровнем моря для каждой точки (при наличии);
  - при наличии — фактическую скорость и/или измеренный расход топлива;
- параметры автомобиля (масса, аэродинамические характеристики, коэффициент сопротивления качению и др.);
- ограничения по скорости и динамике (ограничения ПДД, максимальное допустимое поперечное ускорение и др.).

Для одной конфигурации транспортного средства используются постоянные параметры:

- масса автомобиля m;
- коэффициент аэродинамического сопротивления Cd и фронтальная площадь Af;
- коэффициент сопротивления качению f_roll(v);
- плотность воздуха ρ и ускорение свободного падения g.

Эти параметры применяются для расчёта сил сопротивления движению и требуемой тяговой мощности.

## 1.3. Задача реконструкции маршрута и уклонов (ИИ-модель №1)

Первая подзадача заключается в восстановлении детализированного профиля маршрута по неполному CSV-файлу. Исходный файл содержит около 8000 точек, в то время как для целей моделирования требуется более плотная дискретизация (например, 10000 точек).

Необходимо:

1. Выполнить параметризацию маршрута по длине пути s, вычислив накопленную длину между последовательными точками.
2. Очистить и сгладить высотный профиль h(s) с целью подавления шумов измерений.
3. Построить регрессионную ИИ-модель зависимости высоты от пройденного расстояния h(s), обеспечивающую непрерывный и гладкий профиль рельефа.
4. На основе модели h(s) выполнить пере-дискретизацию маршрута на равномерной сетке по расстоянию, получив 10000 точек sk и соответствующие значения высоты hk.
5. Рассчитать уклон Gk (градиент дороги) для каждой точки по производной высоты по расстоянию.
6. При наличии данных или по геометрии траектории оценить радиус кривизны Rk на каждом участке.

Искусственный интеллект на данном этапе используется в виде регрессионной модели, которая восстанавливает непрерывную функцию высоты h(s) по заданным дискретным точкам и позволяет корректно интерполировать недостающие значения. Это обеспечивает гладкий профиль высот и устойчивое вычисление уклонов, что критично для последующего расчёта расхода топлива.

## 1.4. Модель расхода топлива (ИИ-модель №2)

Вторая подзадача заключается в построении модели расхода топлива как функции скорости, уклона и геометрии дороги.

### 1.4.1. Физическая основа

Для короткого сегмента маршрута длиной Δs_j с уклоном Gj и радиусом кривизны Rj при квазистационарном движении с постоянной скоростью v суммарная сила сопротивления движению определяется как сумма:

F_res(v, Gj) = F_aero(v) + F_roll(v) + F_grade(Gj),

где:

- F_aero(v) = 1/2 ρ Cd Af v^2 — аэродинамическое сопротивление;
- F_roll(v) = m g f_roll(v) — сопротивление качению;
- F_grade(Gj) ≈ m g (Gj/100) — составляющая веса на уклоне.

Требуемая тяговая сила при отсутствии продольного ускорения F_trac = F_res, а соответствующая мощность:

P_trac(v, Gj) = F_trac(v, Gj) · v.

### 1.4.2. Эмпирическая ИИ-модель расхода

Для практического использования вводится эмпирическая ИИ-модель удельного расхода топлива q, зависящего от скорости и параметров дороги:

q(v, Gj, Rj) ≈ a0 + a1 v + a2 v^2 + b1 |Gj| + c1 (v^2 / Rj),

где:

- q — удельный расход топлива (например, в л/100 км);
- v — скорость;
- Gj — уклон в процентах;
- Rj — радиус кривизны;
- коэффициенты a0, a1, a2, b1, c1 оцениваются по данным (измерения расхода или эталонная модель).

Данная зависимость отражает, что:

- в диапазоне скоростей расход топлива имеет выраженный минимум (квадратичная компонента по v);
- повышение уклона |Gj| увеличивает расход (коэффициент b1 > 0);
- движение по малым радиусам кривизны (повороты) также приводит к росту расхода из-за дополнительных потерь и ограничений по динамике (коэффициент c1).

ИИ-модель №2 представляет собой регрессионную модель, которая по набору признаков (v, Gj, Rj, параметры ТС) оценивает удельный расход топлива q. Эта модель может быть реализована в виде линейной/квадратичной регрессии, градиентного бустинга или небольшой нейросети и калибруется по исходным данным.

## 1.5. Оптимизация скорости по маршруту

На основе восстановленного профиля маршрута и модели расхода топлива формулируется задача оптимизации скорости.

Для каждого сегмента j длиной Δs_j с уклоном Gj и радиусом кривизны Rj задаются ограничения по скорости:

- минимально допустимая скорость v_min;
- максимальная скорость по ПДД v_max^ПДД;
- динамическое ограничение по поперечному ускорению:

v_max^дина(Rj) = sqrt(a_y,max · Rj),

где a_y,max — максимально допустимое поперечное ускорение.

Итоговое ограничение по скорости на сегменте:

v_max(Rj) = min(v_max^ПДД, v_max^дина(Rj)).

Задача поиска оптимальной скорости на сегменте формулируется как:

v_j* = argmin_{v ∈ [v_min, v_max(Rj)]} q(v, Gj, Rj),

где q(v, Gj, Rj) задаётся ИИ-моделью №2.

Суммарный расход топлива по маршруту определяется как:

Q = Σ_j q(v_j, Gj, Rj) · (Δs_j / 100 км),

а время в пути:

T = Σ_j (Δs_j / v_j).

Основная цель — минимизировать суммарный расход топлива Q при соблюдении ограничений по скорости и, при необходимости, дополнительных ограничений по времени пути.

## 1.6. Роль веб-приложения и визуализация результатов

Разрабатываемое веб-приложение выполняет следующие функции:

1. Принимает на вход CSV-файл маршрута и параметры автомобиля.
2. Запускает ИИ-модель №1 для восстановления полного профиля высоты и уклонов на заданном количестве точек.
3. Для каждого сегмента маршрута и заданных параметров автомобиля рассчитывает силы сопротивления и вызывает ИИ-модель №2 для оценки удельного расхода топлива.
4. Выполняет оптимизацию скорости по сегментам маршрута, формируя профиль оптимальной скорости.
5. Визуализирует результаты:
   - отображает маршрут на карте с анимацией движения транспортного средства и выделением пройденного пути;
   - отображает текущую скорость, время в пути и расход топлива;
   - строит графики высоты и уклона вдоль маршрута;
   - выводит рассчитанную оптимальную скорость.

Таким образом, веб-приложение интегрирует физически обоснованные расчёты с ИИ-моделями реконструкции маршрута и оценки расхода топлива, предоставляя наглядный инструмент для анализа влияния профиля дороги и скорости на расход топлива.
